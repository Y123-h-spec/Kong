========================================
  空谷设计 · 企业官网 · 使用说明
========================================

【如何打开】
1. 双击本文件夹中的 "index.html" 文件
2. 系统会自动用默认浏览器打开网页
3. 推荐使用 Chrome（谷歌浏览器）、Edge 或 Safari 打开，效果最佳

【交付说明】
- 本文件夹为完整离线网页，无需联网即可正常浏览
- 所有图片、样式、交互均已内置，双击即可观看
- 可直接将整个文件夹压缩为 .zip 后发送给客户

【文件夹结构】
  空谷设计-企业官网/
  ├── index.html          ← 网页主文件（双击打开）
  ├── 使用说明.txt         ← 本文件
  └── images/             ← 所有图片资源
      ├── hero-bg.png          首屏背景
      ├── hotel-1~7.jpg/png    7个酒店案例图
      ├── wellness-1~8.jpg     8个康养案例图
      ├── cert-*.png           资质证书
      ├── contact-*.png        地图、二维码
      └── ...                  其他背景及装饰图

【网页功能】
✓ 苹果极简 + 谷歌Material卡片风格
✓ 7大酒店案例 + 8大康养案例完整展示
✓ 点击案例图片可全屏放大查看
✓ 酒店案例支持按类型筛选
✓ 数字滚动动画、滚动渐入效果
✓ 导航栏自动高亮当前章节
✓ 响应式布局，手机/平板/电脑自适应
✓ 防右键、防复制、防截图快捷键保护
✓ 全屏半透明水印，保护内容版权

【注意事项】
1. 请勿删除或移动 images 文件夹，否则图片无法显示
2. 请勿修改 index.html 文件名
3. 发送给客户时，请将整个文件夹一起发送（建议压缩为zip）
4. 如需修改内容，请用记事本或代码编辑器打开 index.html
