黑金风格企业官网 / 在线作品集，可直接部署到 GitHub Pages。

## 快速部署

### 方式一：GitHub Pages（推荐）

1. 将本文件夹推送到 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. Source 选择 `Deploy from a branch`，Branch 选 `main` / `root`
4. 保存后等待 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

### 方式二：本地预览

直接用浏览器打开 `index.html` 即可。

或启动本地服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## 交互功能

- **顶部阅读进度条** — 实时显示浏览进度
- **固定导航栏** — 9 个锚点跳转，滚动高亮当前章节，移动端汉堡菜单
- **右侧圆点导航** — 11 个章节快速跳转，悬停显示章节名
- **回到顶部按钮** — 滚动超过一屏后出现
- **图片灯箱** — 点击任意案例图片放大查看，支持 ESC 关闭
- **滚动淡入动画** — 内容进入视口时淡入上移
- **键盘导航** — ↑↓ / PageUp/PageDown 翻页，Home/End 跳首尾
- **封面滚动提示** — 底部动画提示向下滚动

## 技术说明

- 纯静态 HTML + CSS + 原生 JS，无任何外部依赖
- 黑金配色：纯黑底 `#080808` + 金属金 `#d4af37` + 纯白文字
- 响应式布局，适配桌面、平板与移动端
- 所有图片已压缩至网页合适尺寸，总资源约 2.5 MB
